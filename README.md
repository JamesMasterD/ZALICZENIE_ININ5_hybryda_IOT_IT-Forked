# Przewodnik po stolicach Europy

## Opis projektu
Projekt „Przewodnik po stolicach Europy” to prosta strona internetowa,
której celem jest prezentacja wybranych stolic europejskich.
Każda stolica opisana jest w osobnej sekcji zawierającej nazwę,
krótki opis oraz zdjęcie.

Projekt realizowany jest w ramach przedmiotu
„Zarządzanie projektem wdrożeniowym”.

## Zakres projektu
- prezentacja stolic Europy
- wykorzystanie repozytorium GitHub
- praca na gałęziach oraz pull requestach
- integracja pracy z narzędziem Trello

## Wykorzystane technologie
- HTML5
- Git
- GitHub
- Trello
